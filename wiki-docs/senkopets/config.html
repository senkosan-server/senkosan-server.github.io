    Основной конфиг¶

    Файл plugins/SenkoPets/config.yml. Плагин не перезаписывает его целиком: в файл только добавляются новые ключи со значениями по умолчанию, поэтому ваши правки сохраняются при обновлении.

    language¶

    Ключ По умолчанию Что делает
    language ru язык сообщений: ru или en. Файл выбранного языка берётся из language/<язык>.yml, если его нет, используется ru.yml

    storage¶

    Ключ По умолчанию Что делает
    storage.type yaml где хранятся питомцы и перезарядки игроков: yaml (папка players/) или sqlite (файл senkopets.db). Неизвестное значение пишет предупреждение в лог и включает yaml

    Подробности, включая автоматическую миграцию между форматами, - в разделе Данные и бэкапы.

    rename¶

    Ключ По умолчанию Что делает
    rename.cost-levels 3 сколько уровней опыта списывается за /pet rename. 0 делает переименование бесплатным. Если у игрока меньше уровней, чем цена, команда откажется работать

    friendship¶

    Очки дружбы начисляются за кормление любимой едой и за поглаживание. Перезарядка своя у каждого питомца, а не общая на игрока.

    Ключ По умолчанию Что делает
    friendship.feed-points 15 очки за кормление любимой едой
    friendship.feed-cooldown-seconds 300 перезарядка кормления одного питомца, в секундах
    friendship.pet-points 10 очки за поглаживание пустой рукой с зажатым Shift
    friendship.pet-cooldown-seconds 180 перезарядка поглаживания одного питомца, в секундах

    Пороги уровней в очках заданы в коде и не настраиваются: 0 / 50 / 125 / 225 / 375, максимум 575. Для курицы пороги умножаются на 4, для летучей мыши - на 6.

    transfer¶

    Ключ По умолчанию Что делает
    transfer.cooldown-use-hours 24 перезарядка передачи питомца в часах для игроков с правом senkopets.use
    transfer.cooldown-extended-minutes 15 перезарядка в минутах для игроков с правом senkopets.extended

    Передавать можно только онлайн-игроку и только питомца, на которого смотрит отправитель. Ванильные прирученные кошки и волки передаются как обычные прирученные животные.

    limits¶

    Ключ По умолчанию Что делает
    limits.max-pets-per-player 5 сколько питомцев может быть у игрока суммарно. 0 снимает ограничение

    Лимит на конкретный вид задаётся отдельно: max-per-player в pets/<вид>.yml. Проверки идут в определённом порядке: сначала лимит вида (со своим сообщением о том, что вид уже приручён), затем общий лимит (сообщением о достижении лимита питомцев). 0 в любом из лимитов снимает соответствующее ограничение. Подробности - в разделе Питомцы.

    combat¶

    Глобальные переключатели поведения питомцев в бою. Питомец участвует в защите, только если включены и общий ключ, и ключ defend-owner в файле его вида.

    Ключ По умолчанию Что делает
    combat.defend-owner true выключает всю систему защиты разом: питомцы перестают атаковать тех, кто бьёт владельца
    combat.assist-owner-attacks true питомцы помогают владельцу атаковать его цель
    combat.defend-radius 24.0 радиус, в котором питомец замечает нападение на владельца, в блоках
    combat.attack-memory-seconds 15 сколько секунд питомец помнит моба, ударившего владельца

    Питомцы не могут атаковать друг друга: урон между питомцами отменяется, цели сбрасываются. Ванильные прирученные волки участвуют в защите наравне с питомцами SenkoPets.

    update-checker¶

    Ключ По умолчанию Что делает
    update-checker.enabled true проверять новые релизы на GitHub через 5 секунд после старта сервера
    update-checker.notify-admins-on-join true писать игрокам с правом senkopets.admin при входе, какая версия доступна

    Пример настроек¶

    language: ru

storage:
  type: sqlite

rename:
  cost-levels: 5

friendship:
  feed-points: 20
  feed-cooldown-seconds: 180
  pet-points: 10
  pet-cooldown-seconds: 120

transfer:
  cooldown-use-hours: 48
  cooldown-extended-minutes: 30

limits:
  max-pets-per-player: 3

combat:
  defend-owner: true
  assist-owner-attacks: true
  defend-radius: 16.0
  attack-memory-seconds: 10

update-checker:
  enabled: false
  notify-admins-on-join: false

    После правок выполните /pet reload - перезапуск сервера не нужен.
