    Команды и права¶

    Плагин регистрирует две команды: /pet и /senkopets. Никаких алиасов у них нет, поэтому если на сервере уже есть команда /pet, она будет перебита - переименуйте её или откажитесь от установки плагина.

    Команды¶

    Команда Что делает Право
    /pet открывает меню питомцев игрока senkopets.use
    /pet stats меню питомца, на которого смотрит игрок senkopets.use
    /pet follow питомец под прицелом идёт следом senkopets.use
    /pet stay питомец под прицелом остаётся на месте senkopets.use
    /pet ability способность брониеносца, лягушки или летучей мыши senkopets.use
    /pet transfer <игрок> передать питомца под прицелом senkopets.use
    /pet help список команд senkopets.use
    /pet rename <имя> переименовать питомца, стоит уровней опыта senkopets.extended
    /pet release отпустить питомца, затем /pet release confirm senkopets.extended
    /pet all follow режим "следовать" всем своим питомцам рядом senkopets.extended
    /pet all stay режим "сидеть" всем своим питомцам рядом senkopets.extended
    /pet reload перечитать конфиги, файлы видов и язык senkopets.admin
    /pet point <игрок> <имя> <очки> начислить или списать очки дружбы senkopets.admin
    /senkopets версия плагина и ссылки -

    Команды кроме /pet reload выполняются только игроком: из консоли на них придёт ответ Эту команду может использовать только игрок.

    Ограничения по расстоянию¶

    Действие Радиус
    Взять питомца под прицел (stats, rename, transfer, release) 10 блоков
    /pet all follow и /pet all stay 50 блоков
    /pet ability 8 блоков
    Подтверждение отпускания /pet release confirm 20 секунд, питомец не дальше 10 блоков

    Команды администратора¶

    /pet reload¶

    Единственная команда, доступная из консоли. Она перечитывает:

    • config.yml - новые ключи в файл при этом дописываются автоматически;
    • все файлы pets/*.yml - их содержимое переписывается плагином, значения сохраняются, неизвестные ключи дописываются в конец;
    • language/ru.yml и language/en.yml - файлы перезаписываются, только если в них не хватает новых ключей;
    • хранилище игроков: текущая база закрывается, новая открывается заново.

    Если в этот момент в storage.type указан другой формат, может произойти миграция данных - подробности в разделе Данные и бэкапы.

    Что /pet reload не делает: не обновляет JAR, не меняет данные питомцев и не запускает проверку обновлений повторно - она выполняется один раз при старте сервера.

    /pet point¶

    /pet point <игрок> <имя питомца> <очки>

    Начисляет или списывает очки дружбы питомцу конкретного игрока.

    • команда требует игрока, из консоли она не работает;
    • игрок ищется по точному имени среди всех известных серверу игроков, включая офлайн;
    • питомец должен быть загружен в одном из миров, иначе его не найти;
    • имя сравнивается без учёта регистра и без кодов цвета &;
    • положительное значение начисляет очки, отрицательное списывает, итог ограничен от 0 до максимума вида: 575 очков, 2300 для курицы и 3450 для летучей мыши;
    • уровень пересчитывается сразу, бонусы к здоровью и урону применяются в тот же момент, в чат отправляется разбор было -> стало.

    Если у игрока несколько питомцев с одинаковым именем, команда вернёт ошибку с их количеством - уточните имя или тип питомца. Примеры:

    /pet point Steve Шарик 200
/pet point Steve Шарик -50

    Подсказка Tab показывает на третьем аргументе имена питомцев игрока, на четвёртом - значения -50, 10, 50, 100, 575. Команда работает и с прирученными ванильными кошками и волками, но очки дружбы у них считаются с нуля.

    Права доступа¶

    Право По умолчанию Что даёт Наследует
    senkopets.use все игроки приручение, кормление, поглаживание, меню, список, езда, /pet stats, /pet follow, /pet stay, /pet ability, /pet transfer -
    senkopets.extended никто /pet rename, /pet release, /pet all, сокращённая перезарядка передачи senkopets.use
    senkopets.admin операторы /pet reload, /pet point senkopets.extended

    Сокращённая перезарядка передачи - это transfer.cooldown-extended-minutes вместо transfer.cooldown-use-hours. Она применяется по наличию права senkopets.extended у отправителя.

    Если снять senkopets.use, игрок теряет не только команды, но и приручение, кормление и меню питомцев.

    Примеры для LuckPerms¶

    /lp group default permission set senkopets.use true
/lp group default permission set senkopets.extended false
/lp group vip permission set senkopets.extended true
/lp group admin permission set senkopets.admin true

    Узлы senkopets.* можно выдать точечно конкретному игроку:

    /lp user Steve permission set senkopets.extended true
