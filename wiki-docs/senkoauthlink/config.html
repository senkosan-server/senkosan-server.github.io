    Основной конфиг SenkoAuthLink-Velocity¶

    Файл plugins/senkoauhlink-velosity/config.yml. Плагин создаёт его при первом старте из банки, а существующий файл не перетирает: своих значений он не добавляет, поэтому новые ключи придётся дописывать руками.

    Перезагрузка есть: /senkoa reload заново читает config.yml и файлы переводов. Но не всё: бот Discord не переподключается, а скомпилированный шаблон текстовой команды бота не пересобирается, и путь к базе не меняется (база открыта один раз при старте). Подробности в разделе Проблемы и решения.

    database¶

    Ключ По умолчанию Что делает
    file database.db имя файла SQLite рядом с конфигом

    Комментарий в самом файле обещает, что при пустом значении возьмётся database.db. Код этого не делает: пустая строка превращается в путь к папке, SQLite не откроет каталог, плагин напишет Could not open SQLite database. Disabling plugin. и отключится. Оставьте значение непустым.

    auth¶

    Ключ По умолчанию Что делает
    require-registration true требовать регистрацию от всех новых игроков. При false новый игрок сразу считается вошедшим, база для него не создаётся
    min-password-length 6 минимальная длина пароля
    max-password-length 32 максимальная длина пароля
    max-login-attempts 5 сколько неудачных попыток входа допускается до отключения
    login-timeout-seconds 60 сколько секунд даётся неавторизованному игроку на вход. 0 отключает таймер
    cooldown-seconds 30 пауза для IP после серии неудачных попыток и после регистрации
    rejoin-grace-minutes 5 авто-вход без пароля, если игрок был за последние N минут. 0 выключает
    initial-server "" сервер, куда отправлять после входа. Пусто - тот, куда игрок шёл сам, иначе первый доступный
    gate-server "" сервер-воронка для неавторизованных. Пусто - игрок остаётся на прокси
    max-players-per-ip 0 сколько игроков одновременно разрешено с одного IP. 0 выключает проверку
    ip-limit-exempt-auth false считать ли только неавторизованных. true - авторизованных в лимит не включают
    ipv6-prefix-length 64 сколько бит IPv6 считать одним адресом. Сравнение идёт по префиксу из ipv6-prefix-length / 16 групп, от 1 до 8
    two-factor-confirm-seconds 120 сколько секунд ждать подтверждения входа. В коде меньше 30 не работает, будет 30
    limbo true удерживать неавторизованного игрока на прокси

    Про limbo стоит знать: комментарий в конфиге говорит, что для этого нужен LimboAPI. Код плагина его не использует - он просто не отправляет игрока на бэкенд (PlayerChooseInitialServerEvent получает null) и выпускает после входа. Если limbo выключить, игрок попадёт на сервер сразу, но чат и команды останутся закрыты.

    premium¶

    Ключ По умолчанию Что делает
    enabled true проверять лицензионность ника через Mojang API
    force-online-auth true требовать online-режим для аккаунтов, привязанных к лицензии
    auth-fallback true разрешать вход по паролю, если online-проверка не прошла
    auth-fallback-minutes 15 сколько минут действует такой вход по паролю, потом проверка повторяется
    api-url https://api.mojang.com/users/profiles/minecraft/{name} адрес проверки, {name} - ник
    cache-ttl-hours 24 сколько часов кэшировать ответ по нику

    Ответы API трактуются так: 200 - ник лицензионный, из тела берётся id; 404 и 204 - ник не лицензионный; любой другой код и любая ошибка - «неизвестно», и плагин такие случаи не трактует как лицензию.

    discord¶

    Ключ По умолчанию Что делает
    enabled false включить привязку Discord
    bot-token "" токен бота. Пустой токен при enabled: true просто отключает Discord с записью в лог
    guild-id "" id Discord-сервера
    verify-command !senko verify {code} текстовая команда в личке боту, резервный способ привязки
    link-code-length 8 длина кода привязки, в коде минимум 4
    link-expiration-minutes 5 сколько минут живёт код, в коде минимум 1
    require-membership true требовать, чтобы игрок состоял на Discord-сервере
    required-role-id "" требовать конкретную роль: id или точное имя. Пусто - не требуется
    check-membership-on-login false проверять членство при каждом входе и отключать, если аккаунт больше не на сервере
    notify-on-login true писать игроку в личку, когда в его аккаунт кто-то вошёл
    admins [] Discord ID пользователей, которым доступны /kick, /ban, /unban в Discord

    Символы в коде привязки - латинские буквы без I и O плюс цифры без 0: ABCDEFGHJKLMNPQRSTUVWXYZ123456789.

    language¶

    Ключ По умолчанию Что делает
    language ru язык сообщений по умолчанию: ru или en

    Другое значение не примет: LanguageManager оставит ru. У конкретного игрока язык меняется командой /senko lang ru и сохраняется в базу.

    Пример настроек¶

    database:
  file: "database.db"

auth:
  require-registration: true
  min-password-length: 8
  max-password-length: 32
  max-login-attempts: 5
  login-timeout-seconds: 90
  cooldown-seconds: 60
  rejoin-grace-minutes: 0
  initial-server: "lobby"
  gate-server: "limbo"
  max-players-per-ip: 3
  ip-limit-exempt-auth: true
  ipv6-prefix-length: 64
  two-factor-confirm-seconds: 180
  limbo: false

premium:
  enabled: true
  force-online-auth: true
  auth-fallback: true
  auth-fallback-minutes: 15
  cache-ttl-hours: 24

discord:
  enabled: true
  bot-token: "токен-бота"
  guild-id: "123456789012345678"
  require-membership: true
  required-role-id: "Player"
  check-membership-on-login: true
  notify-on-login: true
  admins: ["987654321098765432"]

language: "ru"
